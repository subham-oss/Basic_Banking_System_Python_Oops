# 🏦 Bank Management System

A simple **Bank Management System** built using **Python, OOP, JSON, and Streamlit**.

## 🚀 Features

* Create a bank account
* Deposit money
* Withdraw money
* View account details
* Update account details
* Delete account
* Store data using JSON
* Simple Streamlit web interface

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)
* JSON
* Streamlit

## 📂 Project Structure

```text
Bank-Management-System/
│
├── app.py
├── bank.py
├── data.json
└── README.md
```

## ▶️ How to Run

Install Streamlit:

```bash
pip install streamlit
```

Run the application:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

## 💾 Data Storage

Account information is stored in the `data.json` file.
